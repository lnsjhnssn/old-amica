# oldamica.com

Official website and archive for **Old Amica**, a Swedish music project.

The site brings together releases, music videos and other audiovisual work from 2011 to the present, with links to Bandcamp and Spotify.

## Tech

Built with **Astro**, using a minimal, responsive layout focused on album artwork and the music and video archive.
